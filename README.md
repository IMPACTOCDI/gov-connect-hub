# Gov Connect Hub / EmpresasGov

Plataforma de conexão entre o poder público e empresas fornecedoras: catálogo de produtos e serviços, atas, manifestações de interesse e gestão de demandas.

## Tecnologias

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Como rodar

```sh
# Instalar dependências
npm i

# Desenvolvimento (com recarregamento)
npm run dev
```

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run preview` — preview do build
- `npm run lint` — lint
- `npm run test` — testes

## Estrutura

- `src/pages` — páginas da aplicação
- `src/components` — componentes reutilizáveis
- `src/contexts` — estado global (auth, demandas, anúncios, etc.)
